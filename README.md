# Predictive Modeling Using Machine Learning

## Project: Titanic Passenger Survival Prediction

This beginner-friendly college project predicts passenger survival using supervised machine learning. It demonstrates data loading, exploration, data cleaning, missing-value treatment, duplicate removal, outlier handling, data analysis, visualizations, model training, a confusion matrix, and an ROC curve.

## Folder Contents

- `Predictive_Modeling_Titanic.ipynb` — complete submission notebook
- `dataset/raw_titanic_sample.csv` — raw Titanic-style educational sample with deliberate data-quality issues
- `dataset/cleaned_titanic_data.csv` — cleaned dataset ready for analysis
- `visualizations/` — exported example charts for submission or presentation
- `requirements.txt` — required Python packages

## How to Run

1. Open a terminal in this folder.
2. Install the libraries: `pip install -r requirements.txt`
3. Start Jupyter Notebook: `jupyter notebook`
4. Open `Predictive_Modeling_Titanic.ipynb`.
5. Click **Kernel → Restart & Run All**.

## Notes

No CSV was supplied, so this project includes a reproducible Titanic-style educational sample. It is labelled clearly to avoid presenting it as the full historical passenger manifest. The notebook code can also be adapted to a real Titanic CSV by changing the data-loading path and matching column names.
