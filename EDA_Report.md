# EDA Report: Titanic Passenger Dataset

## Objective
Explore the Titanic passenger dataset using statistical summaries and visualizations to identify patterns, relationships, and factors associated with survival.

## Dataset Overview
- **Records:** 453 rows (including deliberate duplicate records)
- **Variables:** Passenger ID, survival outcome, class, gender, age, family information, fare, and embarkation port
- **Data-quality observations:** missing values occur in Age, Fare, and Embarked; duplicate rows are present.

## Main Findings
1. **Gender:** female passengers have a survival rate of 70.9%, compared with 18.1% for male passengers.
2. **Passenger class:** first-class passengers have a survival rate of 56.9%, compared with 31.6% for third-class passengers.
3. **Fare:** fare differs noticeably between passenger classes. This indicates that fare can be used as a useful explanatory feature.
4. **Age:** the passenger distribution is concentrated among young adults, with fewer passengers at older ages.
5. **Preparation for future work:** missing values and duplicates should be treated before using the data in a predictive model.

## Conclusion
The analysis identifies gender and passenger class as the strongest visible factors associated with survival in this educational Titanic-style sample. The project demonstrates how EDA turns raw tabular data into clear, evidence-based insights.
